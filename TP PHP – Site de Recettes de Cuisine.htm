TP PHP – Site de Recettes de Cuisine

Objectif général

Réaliser un mini-site vitrine présentant des recettes de cuisine réparties sur plusieurs pages, en utilisant uniquement PHP côté serveur, sans base de données ni formulaire, avec un système de navigation basique entre pages.
Ce TP permet d’exercer :
La structure d’un projet PHP multi-fichiers
L’usage de
include
,
include_once
,
require
,
require_once
Les manipulations de tableaux, chaînes de caractères, boucles, conditions, fonctions
La séparation logique des données, du contenu, et de l’affichage

Contexte du site

Vous développez un site nommé "Les Délices Maison". Il présente plusieurs recettes de cuisine, des astuces, et une présentation générale du site. Le contenu est fixe (pas de formulaire). Le site doit comporter 4 pages principales maximum.

Structure de navigation (maximum 4 pages)

Page
Description
index.php
Page d’accueil, courte présentation du site et des types de recettes
recettes.php
Liste des recettes disponibles
astuces.php
Astuces et conseils culinaires
apropos.php
Présentation du site et/ou de l’auteur

Organisation des fichiers

Vous devez organiser vos fichiers PHP en plusieurs parties réutilisables :

Dossiers recommandés :

/site-recettes/ │ ├── index.php ├── recettes.php ├── astuces.php ├── apropos.php │ ├── includes/ │ ├── header.php │ ├── footer.php │ ├── menu.php │ ├── data/ │ └── recettes.php │ └── fonctions/ └── utils.php
​
includes/
: contient les fichiers de mise en page réutilisables (en-tête, pied de page, menu)
data/
: contient les données des recettes dans un tableau PHP
fonctions/
: contient des fonctions utiles, par exemple pour formater l’affichage (optionnel)

Détail des pages

index.php

Présente brièvement le site et son but
Inclut un menu commun (
includes/menu.php
)
Appelle un en-tête (
includes/header.php
) et un pied de page (
includes/footer.php
)

recettes.php

Affiche une liste de recettes sous forme de résumé (titre, temps de cuisson, difficulté)
Les données sont stockées dans un tableau dans
data/recettes.php
(voir plus bas)
Utiliser une boucle pour parcourir les recettes
Vous pouvez appliquer une mise en forme libre

astuces.php

Affiche une série d’astuces (stockées directement dans le fichier ou dans un tableau)
Présentation libre : liste, paragraphes, encadrés…

apropos.php

Présente l’auteur ou les intentions du site
Texte libre, mais doit inclure les mêmes éléments de structure (
header
,
footer
,
menu
)

require_once

$recettes

Contraintes techniques

Utilisez
include
,
include_once
,
require
,
require_once
dans différents fichiers.
Mettez en place un menu commun dans
includes/menu.php
.
Le menu doit permettre de naviguer entre les 4 pages.
Aucun formulaire ne doit être utilisé.

Instructions sur le style

Le style est libre : CSS intégré ou externe, avec ou sans bibliothèque.
Encouragez une structure claire du contenu : titres, sections, listes, etc.
Vous pouvez utiliser une feuille CSS globale si vous le souhaitez.

Bonus – Utilisation de
$_GET
(facultatif)

Ajoutez une fonctionnalité bonus sur la page
recettes.php
:
En cliquant sur le titre d'une recette, l'utilisateur est redirigé vers
recette.php?id=2
(à créer).
Cette page bonus affiche tous les détails d’une seule recette en se basant sur l’indice transmis via
$_GET['id']
.
Ce fichier n’est pas obligatoire, mais permet de pratiquer $_GET pour charger dynamiquement du contenu selon l’URL.
